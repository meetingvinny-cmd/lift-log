# How to use Lift Log

## Install (once)

1. Open the app address in Safari on the iPhone.
2. Tap Share (or tap ..., then Share). Tap "Add to Home Screen", keep "Open as Web App" on, tap Add.
3. Open Lift Log from the new icon. Always use the icon. A Safari tab keeps its own separate data.
4. If the icon opens with an address bar, delete the icon and add it again with Open as Web App on.

## Phone check (once, after install)

1. In the app, tap Settings, then Phone check.
2. Tap Run check again once (the screen-awake row is only checked after a tap).
3. Take a screenshot of the screen and keep it.
4. Every row should say Yes. A row that says Unsure or No shows one line on what to do.

## Back up after each workout

The app keeps everything on the phone. Deleting the icon deletes the data. Back up after every workout: tap Back up now on the sheet after Finish day (or Settings, Back up now), then save the file to Files or send it to your computer. A dot on the Settings tab means something is not in a backup yet.

## Restore

Settings, Restore from file, pick a backup file. The app checks the file first and shows what is in it. A bad file changes nothing. Type RESTORE to go ahead. A safety copy of the phone's data is made first; Settings, Undo last restore or erase brings it back.

## Load a block file

Settings, Load a block file, pick the file, check the preview, tap Save block. A newer copy of the same block file updates its later days; days already logged never change.
